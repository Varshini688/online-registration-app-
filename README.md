# Online Registration Web Application

## Files Included
- `index.html`: Registration form interface with jQuery included.
- `style.css`: Responsive UI styling and print-ready receipt styles.
- `script.js`: Client-side validation, AJAX submission, and form reset logic.
- `process.php`: Server-side input sanitization and formatted HTML summary output.
- `Dockerfile`: Ready-to-deploy Apache + PHP 8.2 container configuration for Render or other cloud platforms.
